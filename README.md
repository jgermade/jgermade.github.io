# jgermade.github.io

Landing con los proyectos de jgermade y germadev:

- Inglés: https://jgermade.github.io/ (`index.html`)
- Español: https://jgermade.github.io/es/ (`es/index.html`)

Página estática, sin build. Las dos versiones tienen el mismo marcado y las mismas anclas
(`#play`, `#jackbird`…) y comparten `assets/site.css`, `assets/site.js` e `img/`; un cambio de
contenido se hace en las dos. El enlace EN/ES de la cabecera lleva al mismo proyecto en el otro
idioma.
